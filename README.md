# Aplicación de Rick and Morty

## 🚀 Descripción
Aplicación web moderna desarrollada con Next.js que permite explorar los personajes de la serie Rick and Morty. La aplicación incluye un sistema de autenticación y una interfaz de usuario atractiva con efectos visuales modernos.

## ✨ Características
- 🔐 Sistema de autenticación con credenciales predefinidas
- 🎨 Diseño moderno con efectos de cristal (glassmorphism)
- 🔍 Búsqueda de personajes en tiempo real
- ❤️ Sistema de favoritos
- 📱 Diseño completamente responsivo
- 🖼️ Optimización de imágenes con Next.js Image

## 🛠️ Tecnologías Utilizadas
- Next.js 14 (App Router)
- TypeScript
- Tailwind CSS
- React Icons
- API de Rick and Morty

## 📋 Requisitos Previos
- Node.js 18.0 o superior
- npm o yarn

## 🚀 Instalación
1. Clonar el repositorio:
```bash
git clone [url-del-repositorio]
```

2. Instalar dependencias:
```bash
npm install
# o
yarn install
```

3. Iniciar el servidor de desarrollo:
```bash
npm run dev
# o
yarn dev
```

4. Abrir [http://localhost:3000](http://localhost:3000) en tu navegador
